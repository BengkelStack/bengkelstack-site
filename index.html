Built for Heavy Repair Bays

Engineered with Zero Runtime Dependencies

Most modern POS systems crash or lag during peak repair hours when shop Wi-Fi drops. BengkelStack enforces the Ponytail Standard: absolute minimal code that works, native stdlib execution, and zero supply-chain vulnerabilities.

01

Dual-Tier Dynamic Pricing

Splits retail spare part prices from vehicle-specific installation fees. Dismantling a complex Maxi-scooter CVT automatically charges more labor than a basic moped.

02

SQLite WAL Concurrency

Write-Ahead Logging mode enables simultaneous non-blocking reads and writes across multiple bay terminals. Thread-isolated with 5000ms busy timeout protection.

03

Deterministic Invoice OCR

Local supplier receipt parser for Astra Otoparts, Yamaha, and Denso. Reconciles sum(subtotal) == grand_total with zero AI hallucinations.

04

Idempotency & Net Guards

Unique client transaction UUIDs prevent double-billing on connection retries. Untrusted non-loopback network IPs require timing-attack immune bearer authentication.
